# JonBranding AI Memory Pack

Bu paket ChatGPT, Claude, Gemini, web-agentlar, AI automation botlar va ichki agentlar uchun yagona kontekst sifatida ishlatiladi.

## Fayllar tartibi

1. `01_JonBranding_Master_Context.md`  
   Asosiy strategik xotira. Har bir AI agent birinchi shu faylni o‘qishi kerak.

2. `02_AI_Agent_System_Prompt.md`  
   ChatGPT Project Instructions, Claude Project Instructions, Gemini Gem Instructions yoki boshqa agent system prompt joyiga qo‘yiladigan tayyor prompt.

3. `03_JonBranding_Operating_System.md`  
   Sales, PM, Finance, HR, Marketing, Content, Quality Control va AI automation bo‘yicha operatsion yo‘nalishlar.

4. `04_Daily_Updates_Template.md`  
   Har kuni agent xotirasini yangilash uchun qisqa jurnal shabloni.

5. `05_Sensitive_Light_Context.md`  
   Tashqi tool, freelancer yoki xavfsizligi noaniq AI agentlarga berish uchun qisqartirilgan, nozik ma’lumotlari kamaytirilgan versiya.

6. `06_Memory_Update_Log_Template.md`  
   Har bir muhim qaror yoki o‘zgarishni qayd qilish shabloni.

7. `07_AI_Agent_Roles.md`  
   JonBranding uchun alohida AI agent rollari: Sales Agent, PM Agent, Content Agent, Finance Agent va boshqalar.

## Foydalanish tartibi

### Har qanday yangi AI agentga beriladigan minimal kontekst

1. Avval `02_AI_Agent_System_Prompt.md` ichidagi promptni instructions/system prompt joyiga qo‘ying.
2. Keyin `01_JonBranding_Master_Context.md` faylini knowledge/project file sifatida yuklang.
3. Agar agent operatsion ish qilsa, `03_JonBranding_Operating_System.md` faylini ham yuklang.
4. Har kuni yangi qarorlar `04_Daily_Updates_Template.md` yoki `06_Memory_Update_Log_Template.md` asosida yangilanadi.

## Muhim qoida

Bitta asosiy haqiqat manbasi bo‘lsin: `01_JonBranding_Master_Context.md`.

Har xil AI agentlar turli javob bermasligi uchun barcha agentlarga bir xil master context beriladi. Agar yangi muhim ma’lumot chiqsa, master context yoki daily update yangilanadi.

## Maxfiylik

Bu paket ichida agentlik strategiyasi, maqsadlar, ichki zaifliklar va moliyaviy orientirlar bor. Uni random browser extension, noma’lum AI tool yoki ishonchsiz platformalarga yuklamang. Bunday holatda `05_Sensitive_Light_Context.md` versiyasidan foydalaning.
